# VCMI Async через iCloud Drive

Цей комплект налаштовує асинхронний обмін Hotseat-сейвом VCMI між двома Mac.

Після інсталяції звичайний сценарій такий:

1. Отримуєш email або системне сповіщення.
2. Відкриваєш VCMI.
3. Завантажуєш сейв `ASYNC_GAME`.
4. Робиш свій хід.
5. Зберігаєш під тією самою назвою.
6. Закриваєш VCMI.

Фоновий агент сам:
- пакує всі файли сейва;
- кладе пакет у спільну папку iCloud Drive;
- надсилає email другому гравцеві через Mail.app;
- приймає пакет другого гравця;
- замінює локальний сейв;
- показує системне сповіщення;
- створює локальну резервну копію попередньої версії.

## Перед інсталяцією

На обох Mac:

- однакова версія VCMI;
- однакові моди та їх версії;
- однакова назва сейва;
- iCloud Drive увімкнений;
- Mail.app налаштований, якщо потрібні email;
- VCMI не має бути відкритий під час першого встановлення.

Один гравець створює в iCloud Drive папку `VCMI Async`, ділиться нею з другим гравцем і дає право редагування.

У VCMI створіть Hotseat-партію та збережіть її, наприклад, як:

`ASYNC_GAME`

## Встановлення

1. Розпакуйте ZIP.
2. Відкрийте Terminal.
3. Перетягніть `install-vcmi-async.command` у вікно Terminal.
4. Натисніть Enter.
5. Виберіть:
   - локальну папку `VCMI Saves`;
   - спільну папку `VCMI Async` в iCloud Drive.
6. Введіть свої дані та дані другого гравця.
7. Якщо використовується email, один раз натисніть `Allow`, коли macOS попросить дозволити фоновому агенту керувати Mail.
8. Повторіть установлення на другому Mac, помінявши гравців місцями.

Типова папка сейвів VCMI:

`~/Library/Application Support/vcmi/Saves`

Якщо її там немає, у Finder натисніть `Go → Go to Folder…` і вставте:

`~/Library/Application Support/vcmi`

Потім знайдіть папку `Saves`.

## Перша передача

Поточний сейв під час інсталяції приймається як початковий і автоматично не відправляється.

Гравець, який ходить першим:

1. відкриває сейв;
2. робить хід;
3. зберігає під тією самою назвою;
4. закриває VCMI.

Через приблизно 20–40 секунд пакет з'явиться в iCloud і буде надіслано email.

## Діагностика

Основний лог:

`~/Library/Application Support/VCMIAsync/logs/agent.log`

Помилки процесу:

`~/Library/Application Support/VCMIAsync/logs/stderr.log`

Перезапуск агента:

```bash
launchctl kickstart -k "gui/$(id -u)/dev.romaniv.vcmi-async"
```

Перевірка, чи агент працює:

```bash
launchctl print "gui/$(id -u)/dev.romaniv.vcmi-async"
```

## Видалення

```bash
launchctl bootout "gui/$(id -u)/dev.romaniv.vcmi-async"
rm -f ~/Library/LaunchAgents/dev.romaniv.vcmi-async.plist
rm -rf ~/Library/Application\ Support/VCMIAsync
```

Спільну папку iCloud Drive можна видалити окремо вручну.

## Обмеження

- Не відкривайте одну партію одночасно на двох Mac.
- Перед відкриттям гри дочекайтеся системного сповіщення або переконайтеся, що iCloud завершив синхронізацію.
- Не оновлюйте VCMI чи моди посеред партії.
- Email надсилається через Mail.app на Mac того, хто завершив хід. Доступ до Mail перевіряється один раз під час запуску агента, а не перед кожним листом.
- Якщо доступ до Mail не надано або надсилання повернуло помилку, email вимикається до наступного перезапуску агента. Обмін сейвом через iCloud продовжує працювати.
- Якщо Mac відправника не має інтернету, iCloud і email підуть після відновлення з'єднання.
